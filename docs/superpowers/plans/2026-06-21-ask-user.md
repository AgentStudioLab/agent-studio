# Ask User Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完整实现 SDK 默认 `AskUserQuestion`，并把 ask-user 与 tool approval 在状态、协议、UI、文案和测试中清晰隔离。

**Architecture:** 复用现有 AGUI interrupt/resume 传输骨架，但将人工等待状态迁移到中性的 `awaiting_user`，具体语义由 interrupt `reason` 决定。后端保持 `requestApproval` / `requestAskUser`、`resolve` / `resolveAskUser` 两条域内路径，前端根据 reason 渲染 `ToolApprovalCard` 或 `AskUserCard`。

**Tech Stack:** Bun test runner, Hono sidecar routes, bun:sqlite store, React 19, TypeScript, Tailwind v4 with Agent Studio design tokens, i18next.

---

  const appended: unknown[] = [];
  const finished: Array<{ runId: string; status: string }> = [];
  return {

        appended.push(event);

    } as unknown as RunEventStore,

}
